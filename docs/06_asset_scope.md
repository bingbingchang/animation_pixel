# 资产范围与再利用说明

本档案按用户明确要求整理当前会话图片作为研究案例。保存原文件不等于确认其可以作为游戏商业素材再发布。

- G01–G15：当前会话图像生成结果；保留generation_id、原始文件名与SHA-256。多数是失败或局部成功案例，没有一个因此自动成为production-ready。
- R00：用户上传的原始像素剑士。作者/来源/许可未提供，标为用户参考，不擅自赋予开放许可。
- R01、R06–R08：用户提供的拳皇GIF和DNF截图，仅用于动作分析。
- R02–R05：从拳皇GIF制作的接触表/片段图，第三方参考派生内容，不是自有角色资产。

不将本项目的代码许可证自动覆盖所有图像；本次不擅自替用户选择全仓库开源许可。外部项目链接也不等于获得其全部图片的再授权。

在公开发布可复用游戏素材包之前，需单独核对每项来源和许可。发布目录应排除第三方参考，研究档案与游戏release分开。

## 文件完整性

原始资产按字节复制；完全相同的重复附件只保留一份。诊断裁切和预览另存于`assets/previews/`，不替换原件。

历史实际模型提示词、seed和底层模型版本不可从generation_id反推出。旧“DALL-E generation metadata”的表面标签不应被当作底层模型身份证明。
